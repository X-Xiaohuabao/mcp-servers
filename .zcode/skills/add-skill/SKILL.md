# 技能维护

## 目录结构

```
.zcode/skills/<skill-name>/SKILL.md
```

- 一个技能一个目录
- 目录名使用 kebab-case
- 入口文件固定为 `SKILL.md`

## Frontmatter

```markdown
---
name: skill-name
description: |
  一句话说明技能用途。

  触发场景：
  - 场景一
  - 场景二

  触发词：关键词1、关键词2、关键词3
---
```

要求：

- `name` 与目录名一致
- `description` 写清"什么时候用"
- 触发词覆盖用户可能的说法
- 中英文术语都列

## 正文结构

```markdown
# 标题

## 适用场景 / 工程信息

## 核心规则 / 步骤

## 命令与示例

## 检查清单

## 常见问题
```

## 新增技能后

1. 技能清单由 hook 动态扫描各 SKILL.md frontmatter 生成，无需手动维护列表；确认 frontmatter 含 `触发词` 行即可
2. 触发词与技能描述保持一致
3. 如涉及命令，补充到 `.zcode/commands/`
4. 不与其他技能职责重复

## 质量要求

- 技能内容基于本仓库实际结构，不照搬其他项目
- 命令与路径必须真实存在
- 不写无法验证的规范
- 保持精简，避免长篇理论

## 修改技能

- 先确认触发场景是否变化
- 更新 description 与触发词
- 检查引用该技能的命令和 hooks 是否需要同步修改
